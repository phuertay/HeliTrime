Helitrime is a privacy-conscious open-source keyboard. It is HeliBoard with 26-key pinyin and character lookup. It does not use the internet permission, so it stays offline.

The package is helitrime001.keyboard. Install the APK from this project's GitHub releases. HeliBoard from F-Droid is a different app.

Pinyin:
<ul>
  <li>Type on a qwerty layout. An apostrophe key splits syllables</li>
  <li>Space commits the first candidate. 1–9 and a tap commit another one</li>
  <li>Long-press comma and choose 简/繁. The space bar shows 中文·简 or 中文·繁</li>
  <li>查 looks a character up by radical or by handwriting</li>
  <li>The globe key leaves Chinese for the next language</li>
  <li>Password, email, and URI fields stay in ASCII</li>
  <li>The Latin personal dictionary is not imported into the pinyin dictionary</li>
</ul>

z/zh, c/ch, s/sh, n/l, an/ang, en/eng, and in/ing count as the same sound. Phrase order uses the octagram language model and has not been hand-tuned.

Also from HeliBoard:
<ul>
  <li>Dictionaries for suggestions and spell check</li>
  <li>Themes, colors, and a background image, including day/night and dynamic colors</li>
  <li>Custom layouts, multilingual typing, clipboard history</li>
  <li>One-handed mode, a split keyboard, and a number pad</li>
  <li>Glide typing only with a closed-source library, which is not included</li>
  <li>Backup and restore of settings and learned words</li>
</ul>
